# Doll Hunt v26 — Realistic Natural Interior

## Art direction
Replaced the pale pastel/floral look with a modern natural home palette: mineral greige plaster, muted sage accent walls, walnut wainscot/paneling, natural oak-walnut floorboards, limestone kitchen tiles, dark bronze window frames, and subdued smoked/sage glazing.

## Visual fixes
- New high-detail plaster texture with subtle trowel marks and mineral grain.
- Desaturated natural wood floor texture with deterministic grain and knots.
- Travertine/limestone tile material for kitchen.
- Rich walnut lower-wall paneling and restrained bronze trim.
- Realistic conventional window mullions; removed bright lime/cyan X/chevron glass appearance.
- Reduced ambient, hemisphere, sun, point-light and hanging-lamp energy.
- Reduced haze/fog and fixed exposure across all graphics presets.
- LOW/MEDIUM/HIGH/ULTRA now change performance quality without changing colour exposure drastically.
- Added Mineral Plaster as a paint/surface pattern option; wall camouflage reports plaster pattern.

## Preserved
All gameplay, practice, AI, Hider mastery, matchmaking, HUD, painting, wall/ceiling attachment and Colyseus server source from v25 were retained; no server code was changed in this visual-only update.

## Validation limits
Static checks are documented in VALIDATION_REPORT_v26.md. Actual Android/WebView rendering and FPS need device testing.
