# Doll Hunt HUD — Where each control lives

This guide explains the revised v23 tablet/mobile play layout.

| Screen zone | Controls | What they do |
|---|---|---|
| Top-left | Player status | Shows role and seeker/player count |
| Upper-left below status | Hider Mastery | Select an unlocked Hider power and activate it |
| Top-right | Minimap + Fullscreen | Read the map and toggle fullscreen |
| Right-middle, upper group | Climb Wall ▲ / ▼ | Move up/down while attached to a wall |
| Right-middle, lower group | Doll Height ▲ / ▼ | Adjust the Doll's height |
| Bottom-right | FIRE / JUMP | Seeker firing and player jump controls when available |
| Bottom-left | Joystick | Player/camera movement according to current game mode |
| Left edge | Pause | Pause/open game menu |

Controls are deliberately split into independent screen zones. The climb, height and power groups no longer share the same right-bottom area.

For best operation, use landscape orientation on a tablet. Portrait and short-landscape layouts are also provided. If the device browser adds large system bars or the app runs in an unusual WebView inset mode, verify tap areas on that device before release.
